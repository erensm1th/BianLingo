# BianLingo

[English](README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md) · [한국어](README.ko.md)<br>
[Français](README.fr.md) · [Deutsch](README.de.md) · [Español](README.es.md) · [Português (Brasil)](README.pt-BR.md) · **Русский**

**Перевод чата World of Warcraft в реальном времени.** Читайте сообщения на выбранном языке и переводите ответы в компактном окне поверх игры.

[Сборка из исходников](docs/BUILDING.md) · [Конфиденциальность](PRIVACY.md)

BianLingo — бесплатный некоммерческий фанатский проект. Он не связан с Blizzard Entertainment, не одобрен и не поддерживается Blizzard.

## Возможности

- **Локальный или сетевой перевод**: Bergamot, CTranslate2, Ollama либо подключение с собственным адресом, моделью и ключом API. Поддерживаются форматы OpenAI-совместимых сервисов, Anthropic и Gemini.
- **Подготовка моделей до игры**: выберите язык перевода и загрузите нужные языковые пары. Доступность языков зависит от движка и модели.
- **Окно чата**: перемещение и изменение размера, прозрачность фона, размер шрифта, темы и пользовательские оформления.
- **Вкладки чата**: отдельные названия и фильтры типов сообщений; импорт конфигурации, экспортированной аддоном из игры.
- **Ответ по щелчку**: левая кнопка готовит ответ в канале сообщения. Меню правой кнопки содержит личное сообщение, ручной запрос уровня и блокировку. Enter переводит и копирует текст; вставку и отправку в игре вы выполняете сами.
- **Фильтры**: каналы, шум и имена с письменностью выбранного языка. Защита ссылок и игровых терминов; отдельные инструкции для входящих сообщений и ответов.
- **Ручная повторная передача**: аддон хранит в памяти 10 полных сообщений по умолчанию; предел настраивается от 1 до 100. Правая кнопка на миникарте или `/bl replay` передаёт их снова. Дубликаты не переводятся повторно.
- **Пиксели и OCR**: компактная цветная матрица либо двоичная сетка; скрытие при простое с небольшим индикатором состояния. В Windows доступно распознавание выбранной области чата.
- **Необязательные журналы**: по умолчанию выключены. Входящие сообщения и подтверждённые задания перевода ответа добавляются в ежедневные файлы UTF-8.
- **Переносимые данные**: настройки, журналы, загруженные модели и кеш приложения находятся в `UserData` рядом с `BianLingo.exe`.

## Варианты перевода

| Движок | Возможности | Ограничения | Применение |
|---|---|---|---|
| **Сетевой API** | Инструкции и стили без загрузки модели | Сеть, квоты, оплата и правила обработки данных провайдера | Управление инструкциями без локального запуска модели |
| **Ollama** | Локальная LLM с инструкциями и стилями | Загрузка среды и модели; память и задержка зависят от оборудования | Локальная обработка с инструкциями |
| **Bergamot** | Автономный перевод на CPU без оплаты API | Подготовленные языковые пары; без инструкций | Поддерживаемая автономная пара |
| **CTranslate2** | Автономный CPU INT8 без оплаты API | Подготовленные пары OPUS-MT; без инструкций | Автономная пара OPUS-MT |

Автоматический выбор направления Bergamot/CTranslate2 предполагает английский исходный текст, а при переводе на английский выбирает китайский по иероглифам Han. Загрузка новых пар не добавляет универсального определения языка. Локальная обработка не отправляет чат провайдеру перевода. Задержка и результат зависят от модели, языковой пары, сообщения, оборудования и сети.

### Benchmark · AMD Ryzen 7 9700X

| Способ | Медиана EN→ZH / ZH→EN | Пиковая RAM | CPU при непрерывном переводе | Корректные ответы API | Наблюдения |
|---|---:|---:|---:|---:|---|
| **Bergamot** | **13 / 19 ms** | **439 MiB** | **3.3%** | 72/72 | Наименьшая задержка; ошибки в некоторых игровых сокращениях и терминах |
| CTranslate2 | 64 / 90 ms | 450 MiB | 18.1% | 72/72 | Низкая задержка; ошибки в игровых терминах |
| Qwen3 0.6B | 181 / 99 ms | 1.09 GiB | 49.6% | 69/72 | Пропуски и копирование примеров из промпта |

Измерения движков на CPU для английского ↔ упрощённого китайского. CPU означает нагрузку при непрерывном переводе, а не в простое. Корректный ответ API не означает точный перевод. Захват экрана, OCR, интерфейс и прямые подстановки из словаря исключены.

### Начальные настройки API

Это примеры обычных пользовательских подключений; они не меняют язык интерфейса или перевода. DeepSeek Flash поддерживает запросы без режима рассуждения; Google указывает перевод среди задач Gemini 3.5 Flash-Lite. Источники: [DeepSeek](https://api-docs.deepseek.com/), [модель Gemini](https://aistudio.google.com/docs/models/gemini-3.5-flash-lite), [задачи и цены Gemini](https://aistudio.google.com/docs/pricing#gemini-3.5-flash-lite).

| Параметр | DeepSeek | Google Gemini |
|---|---|---|
| Базовый URL | `https://api.deepseek.com` | `https://generativelanguage.googleapis.com/v1beta/openai` |
| Модель | `deepseek-flash` | `gemini-3.5-flash-lite` |
| Ключ API | [DeepSeek Platform](https://platform.deepseek.com/) | [Google AI Studio](https://aistudio.google.com/apikey) |
| Дополнительные параметры | `{"thinking":{"type":"disabled"}}` | `{}` (настройки модели) |

Добавьте подключение в **API & usage**. Выберите **OpenAI Chat Completions** (`openai_chat`), авторизацию **Auto**, оставьте **Full URL** выключенным и введите свой ключ. В расширенных настройках укажите параметры из таблицы; пользовательские заголовки оставьте пустыми, запрос баланса — выключенным. Сохраните и проверьте подключение. См. [настройки подключений](docs/PROVIDERS.md) и [совместимый с OpenAI API Google](https://aistudio.google.com/docs/openai).

Доступность моделей, цены, квоты и обработку данных определяет провайдер: [цены DeepSeek](https://api-docs.deepseek.com/quick_start/pricing/), [цены и данные Gemini](https://aistudio.google.com/docs/pricing), [регионы Gemini](https://aistudio.google.com/docs/available-regions). Бесплатный и платный уровни Gemini имеют разные ограничения и условия использования данных.

## Как это работает

1. **Аддон BianLingo** читает сообщения через API аддонов и ненадолго показывает закодированные пиксели в углу игры.
2. **Настольное приложение** декодирует пиксели, переводит выбранным подключением и отображает результат поверх игры.

Приложение не читает память игры, не внедряет код и не отправляет чат автоматически. OCR захватывает выбранную область. Если Blizzard скрывает текст от аддонов, пиксельная передача не может его восстановить; OCR служит отдельным источником ввода.

## Требования и языки

| Платформа | Статус |
|---|---|
| Windows 10/11 x64 | Доступно. Оконный OCR требует Windows 10 1903 или новее. |
| macOS | В разработке, поддержка планируется в будущем выпуске; сборки для macOS пока нет. |

- World of Warcraft с аддоном BianLingo в оконном режиме или окне без рамки.
- Локальная модель либо собственное подключение API. Полный пакет включает Bergamot для английского ↔ упрощённого китайского; другие доступные пары подготавливаются отдельно.

Интерфейс поддерживает английский, упрощённый китайский, японский, корейский, французский, немецкий, испанский, бразильский португальский и русский языки. Выберите **Язык интерфейса** в разделе **Оформление чата** и сохраните настройки: изменения применяются сразу. По умолчанию используется язык системы; для неподдерживаемых локалей — английский, для китайских — упрощённый китайский. Языки интерфейса, README и перевода независимы. Поддержка перевода зависит от движка и модели. Ошибки и уведомления о состоянии отображаются на китайском в китайском интерфейсе и на английском во всех остальных языках интерфейса.

Аддон декларирует поддержку Classic Era и совместимых клиентов Classic/Retail. Доступ к чату зависит от клиента и ситуации. HDR, мониторы с разным DPI и версии игры требуют проверки в конкретной среде.

## Быстрый старт

1. **Установить аддон.** Скопировать `AddOns/BianLingo` в `World of Warcraft/<client>/Interface/AddOns/`, например в `_retail_`, `_classic_era_` или `_forever_`. Проверить файл `Interface/AddOns/BianLingo/BianLingo.toc`, включить аддон в игре и выполнить `/reload`.
2. **Запустить и переместить окно.** Оставить `BianLingo.exe` рядом с `data` и запустить EXE. **Щелчок по коту справа вверху открывает настройки; перетаскивание того же значка перемещает окно.**
3. **Выбрать переводчик.** В настройках API выбрать подключение. **Bergamot / CTranslate2:** выбрать целевой язык чата и подготовить текущий языковой пакет либо открыть управление пакетами для предварительной загрузки. **Ollama:** выбрать и скачать модель; ключ API не нужен. **Онлайн-API:** выбрать или добавить подключение, указать базовый URL, модель и ключ API, сохранить и проверить. Примеры приведены выше.
4. **Настроить входящий перевод.** Выбрать целевой язык чата в настройках API и каналы в области перевода, затем сохранить. Для локального перевода нужна поддерживаемая и подготовленная языковая пара.
5. **Перевести ответ.** Стандартная клавиша — **· / обратная кавычка (&#96;), обычно под Esc**. Ввести текст и нажать **Enter** для перевода и копирования; вставить в игру вручную. В настройках исходящего перевода выбрать язык и стиль. Для смены сочетания щелкнуть его поле, нажать новые клавиши и сохранить. Языки входящего и исходящего перевода задаются отдельно.
6. **Синхронизировать окна чата.** Настроить окна и каналы в WoW. При запущенном EXE выполнить `/bl windows` или выбрать синхронизацию в `/bl settings`. После полного получения настройки автоматически **заменяют** вкладки; отдельный импорт не требуется. Аддон должен быть включен.


Используйте приложение и аддон из одного пакета. Для получения китайского чата с переводом на другой язык выполните `/bl cn off`, если китайский фильтр аддона включён.
