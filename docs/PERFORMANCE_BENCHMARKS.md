# Measuring performance

Use `tools/benchmark_translation.cpp` and the local benchmark scripts to measure a selected engine with synthetic text. The benchmark tools are development utilities and are not distributed with the application.

Measure warm/cold translation latency, process-tree CPU, working set and idle use separately from screenshot decoding and UI rendering. Include the model, language direction, thread settings, hardware, source revision and sample set. API tests can incur provider charges.

For game performance, compare the same scene and settings with the addon and receiver separately enabled. Engine-only measurements do not establish game FPS or end-to-end latency. Avoid replacing actual Windows 10 or HDR/mixed-DPI acceptance with a hosted build result.
